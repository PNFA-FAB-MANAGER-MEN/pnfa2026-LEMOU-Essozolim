## Fait aujourd'hui

### 1. Fabrication assistée par ordinateur : modélisation d'un circuit électronique avec KiCad

**Cours présenté par : Arnauld Kpadenu**

L'objectif de la séance était de partir d'un projet et de réaliser la **modélisation d'un circuit électronique** à l'aide du logiciel **KiCad**.

Nous avons travaillé sur la conception d'un circuit permettant de réaliser un **allumage de LED avec le XIAO ESP32-S3**.

Les principaux éléments étudiés étaient :

1. Une résistance ;
2. Un écran OLED ;
3. Un bouton-poussoir ;
4. Deux résistances supplémentaires ;
5. Un condensateur.
![Allumer une led](<../medias/Allumer une led 09_09_2026.png>)
Nous avons également appris à :

* ajouter la bibliothèque de composants nécessaire, notamment celle de l'écran OLED, dans KiCad ;
* rechercher et placer les composants dans le schéma électronique ;
* réaliser les connexions entre les différents composants ;
* attribuer les **empreintes (footprints)** aux composants afin de préparer leur fabrication sur une carte électronique.

Cette activité m'a permis de mieux comprendre le passage d'une idée ou d'un montage électronique vers une **conception structurée d'une carte électronique**.

### 2. Notions fondamentales de programmation et d'informatique

La deuxième partie de la journée a été consacrée aux bases de la programmation et de l'informatique.

Nous avons étudié les **six concepts fondamentaux de la programmation** :

* les variables ;
* les boucles (*loops*) ;
* les structures conditionnelles ;
* les fonctions ;
* les commentaires ;
* les opérateurs.

Concernant les opérateurs, nous avons abordé notamment :

* les **opérateurs arithmétiques** : addition, soustraction, multiplication, division, modulo, etc. ;
* les **opérateurs logiques** : `AND`, `OR`, `NOT` ;
* les **opérateurs de comparaison** ;
* les **opérateurs d'affectation**.

Nous avons également abordé la notion d'**informatique**, définie comme la science du traitement automatique de l'information par un ordinateur.

L'information peut prendre différentes formes, notamment :

* audio ;
* texte ;
* visuel ;
* image ;
* vidéo.

Nous avons aussi étudié les principaux éléments qui composent un ordinateur :

* le **matériel (hardware)**, comprenant notamment les périphériques d'entrée et de sortie ;
* les **logiciels (software)**.

Une introduction au **langage binaire ou langage machine** a également été faite. Nous avons vu que l'ordinateur traite les informations sous forme de données binaires.

Enfin, nous avons abordé le rôle du **BIOS**, qui intervient au démarrage de l'ordinateur avant le chargement du système d'exploitation.

### 3. Programmation de notre projet

Nous avons commencé à réfléchir à la programmation de notre projet afin de mettre en pratique les notions étudiées.

L'objectif est de progressivement programmer le système à partir du **XIAO ESP32-S3** et des différents composants du projet.

Cette étape doit permettre de passer de la conception électronique à un **prototype fonctionnel**, en combinant le matériel et le programme.

## Raté, puis corrigé

Lors de la conception du circuit dans KiCad, certaines difficultés sont apparues dans la recherche des composants et dans l'utilisation des bibliothèques.

Nous avons appris à rechercher les composants appropriés et à vérifier leurs caractéristiques avant de les intégrer au schéma.

L'attribution des empreintes constitue également une étape importante : il faut s'assurer que l'empreinte choisie correspond bien au composant qui sera réellement utilisé lors de la fabrication de la carte.
